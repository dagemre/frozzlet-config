- version.json → "YENİ SÜRÜM" kartı. latest > oyundaki sürüm = kapatılabilir kart; min > sürüm = zorunlu güncelleme.
- ios: TestFlight döneminde itms-beta://, yayından sonra https://apps.apple.com/app/id6825335384
- cfg → uzak ayarlar (sadece sayı / aç-kapat; v2.45+ okur). Anahtar listesi: Project doc claude/UZAK-AYARLAR.md. 14 Kas 2026: rush_carry 150 (hızlı turdan yeni haritaya geçen coin tavanı × harita no; harita 2'ye 300).
